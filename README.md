## What it does

`main.ts` writes a single line of text — one quiet, earned moment of pride — to `/output/entry.txt`. No network calls, no environment secrets, no reads from git history or files outside this repository. The output is deterministic and always 1–240 UTF-8 characters.

Run locally with Node 22.18+:

```
node main.ts
```
